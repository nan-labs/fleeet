---
title: Open source and hosted
description: Which parts of Fleeet are open source and which are a hosted service
---

Fleeet has two parts.

**Open source ([nan-labs/fleeet](https://github.com/nan-labs/fleeet), MIT):** the fleeet-reporting skill, the `fleeet-emit` CLI, the event format ([schema](https://github.com/nan-labs/fleeet/blob/main/schema/event-schema.json)), the MCP setup guides and this docs site. You can read, fork and change them, and use the event format with any server.

**Hosted and closed:** the board service at [fleeet.space](https://fleeet.space), including its MCP server, API, storage and sanitizer. Its source isn't public.

What the kit sends and what the board stores is in [PRIVACY.md](https://github.com/nan-labs/fleeet/blob/main/PRIVACY.md).
