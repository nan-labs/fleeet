# Governance

Fleeet is a small project with a single maintainer.

## Maintainer

- Ronan Flynn-Curran ([@flynnduism](https://github.com/flynnduism))

The maintainer reviews and merges pull requests, decides on proposals, cuts releases and enforces the [Code of Conduct](CODE_OF_CONDUCT.md). [CODEOWNERS](.github/CODEOWNERS) lists who reviews which files.

## How decisions get made

Proposals start as GitHub issues. Anyone can comment. The maintainer makes the call, aiming for rough consensus among the people involved, and writes the reason on the issue. Changes that break the event schema or the skill need a major version and a note in the changelog.

## Becoming a maintainer

Contributors who have landed steady, good-quality work and helped others in issues may be invited to become maintainers. When there's more than one, this document will describe how they decide together.

## Changes to this document

Through a pull request, like any other change.
